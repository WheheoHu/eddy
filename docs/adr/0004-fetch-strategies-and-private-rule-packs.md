# 0004 抓取策略引擎和私有规则包

状态：已采纳

## 决定

- 公开仓库里只有通用的 `FetchStrategy` 流水线：直接请求、按规则换请求头、注入用户自己的 Cookie、查询存档站点、交给平台 WebView 抓取。
- 站点级规则（某个站用什么请求头、Cookie、是否查存档）写在私有规则包里，格式见 `crates/eddy-fetch/README.md`。规则包从本机文件导入，服务端模式下由服务端配置下发，任何公开仓库都不收录。
- 优先使用合法访问：用户已登录的会话（通过 Chrome 扩展捕获已经能看到的页面）。

## 理由

2024 年 8 月，GitHub 依据 DMCA 第 1201 条（反规避条款）下架了 Bypass Paywalls Clean，连带 3,879 个 fork。站点规则一旦进公开仓库，整个仓库网络都可能被禁用。

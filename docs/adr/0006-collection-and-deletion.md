# 0006 Collection 和删除

状态：已采纳

## Collection

订阅文章之外的内容统称 Collection，界面上和订阅源并列。它是内核在现有存储上给出的视图（`Engine::collection()`），存储结构和同步协议不变：

- 系列各成一项：没有目录页地址（`toc_url`）的是导入的书（Book），有的是从网页目录生成的系列（Web Series）。
- 单独保存的条目（`ItemKind::Saved`，不属于任何系列）各成一项，按单章处理：PDF 归为 PDFs，其余归为 Web Pages。
- 已经并入系列的网页只出现在它所在的系列里。生成系列的目录页（地址等于系列 `toc_url` 的保存网页）同样归系列所有，不再单独列在 Web Pages 里。
- 每项给出打开时要读的章节：上次停下的那一章，读完了就是它之后第一章没读完的，从没读过就是第一章。

单个 PDF 或网页的目录由平台从文档自带的大纲（PDF 书签、网页标题）生成，不在内核里拆成章节。

## 删除

- 只有 Collection 里的内容能删除，订阅文章属于它的订阅源，删除时报错。
- 删除走操作日志：系列记 `Series.deleted`，它的每一章和单独的条目记 `Item.deleted`，和其他修改一样同步到所有设备。删系列时章节一起删，并入系列的网页和它的目录页也随系列删除。
- 删除后从搜索索引里移除，并清掉只有已删除条目用到的内容 blob，包括固定存储的原文件。本机删除和同步收到的删除都这样处理；服务端的 blob 暂不回收。
- 删除不能恢复。同一个文件删除后再导入，按新内容处理。

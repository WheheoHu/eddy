# 0007 媒体解析和 Gallery

状态：已采纳

## 决定

- 图片和视频为主的内容在第三个顶层视图 Gallery 里浏览。进入 Gallery 的是被标记的订阅源（单个源用 `Source.gallery`，整个文件夹用同步设置 `gallery.folders`），以及链接指向媒体的保存条目（Collection 的 Media 分类）。被标记的订阅照常出现在三栏视图里。
- 条目链接到媒体时，由 `eddy-media` 把链接解析成可以直接显示或播放的媒体列表（图片、视频地址、嵌入播放器的视频 ID）。解析按需进行，结果只存在本机的 `media_sets` 表里，不进操作日志：它随时能从链接重新算出，地址也会过期。
- 视频不进本地缓存，只缓存封面和图片，和其他图片一样受缓存上限约束。

## 和私有规则包的区别

ADR-0004 规定站点规则只放私有规则包，因为绕过付费墙的规则可能被依据 DMCA 第 1201 条下架。`eddy-media` 的解析器放在公开仓库，理由是它们不规避任何访问控制：

- 只读取站点公开提供给匿名访客的内容：公开接口（例如 RedGIFs 发给匿名网页访客的临时 token）、页面里本来就有的媒体地址、视频链接里的 ID。
- 页面要求登录时（Reddit 的 18+ 遮罩），解析器报告"需要登录"，由用户在 Eddy 的内置浏览器里用自己的账号登录，不伪造会话、不绕过遮罩。
- 解析器只认链接格式和页面结构，不含 Cookie、请求头之类的站点访问规则；这类规则仍然只能写在私有规则包里。

站点改版导致解析失败时，条目退回订阅自带的缩略图。

# 0005 AI 在客户端执行

状态：已采纳

## 决定

- 翻译、摘要、自动标签由客户端内核直接调用模型（先支持 OpenAI 兼容的 Chat Completions）。API Key 只存在本机钥匙串，不同步。
- 触发条件在客户端配置：手动触发，或按订阅源设置自动规则，有每日次数上限。
- 结果按"内容哈希 + 模型 + 目标语言 + 提示词版本"缓存。翻译和摘要可以分别选择跨设备同步或只留本机；确认过的标签始终同步。
- 标签使用受控词表：模型只能从词表里选，新标签作为建议，由用户确认后加入。标签只存在 Eddy 里，不回写 FreshRSS。
- 自动触发前先查已同步的结果，避免多台设备重复花钱。

## 理由

AI 是建立在阅读器上的功能，作用于正在读的内容；放在客户端让单机模式也完整可用，Key 也不必离开设备。
